Installation information
=======

1. Download this mod from here: https://modrinth.com/mod/liminalness
   - As a dependency, you must also have the 1.21.1 version of TACZ: https://modrinth.com/mod/tacz-1.21.1
2. Place the mod(s) in your mods folder

Build information
=======
`gradlew build`

`gradlew runClient`
